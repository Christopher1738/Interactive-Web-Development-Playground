# Interactive Web Playground 🎮

## Overview
A feature-rich interactive web application demonstrating core JavaScript concepts including:
- Event handling 🎈
- DOM manipulation 🎮
- Form validation 📋
- Interactive UI components ✨

## Features

### 🎈 Event Handling
- Click counter with visual feedback
- Hover effects with CSS transitions
- Keyboard input detection
- Secret double-click/long-press action

### 🎮 Interactive Elements
- Color-changing button
- Auto-playing image slideshow with navigation
- Accordion FAQ section
- CSS/JS animations (bouncing ball)

### 📋 Form Validation
- Real-time input validation
- Password strength meter
- Visual feedback for errors/success
- Submission handling

## Technologies Used
- HTML5
- CSS3 (Animations, Flexbox, Transitions)
- JavaScript (DOM API, Event Handling)
- [Placehold.co](https://placehold.co) (Image placeholders)

No installation required! Simply:
1. Clone this repository
2. Open `index.html` in any modern browser
3. Interact with all the demo components
